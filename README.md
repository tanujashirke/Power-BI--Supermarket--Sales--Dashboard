# Power-BI--Supermarket--Sales--Dashboard

## Overview
This Power BI dashboard analyzes supermarket sales performance, profitability, and growth trends using interactive visualizations.

## Key KPIs
- Total Sales: 12.64M
- Total Profit: 1.47M
- Profit Margin: 11.6%
- YoY Growth: 51.5%

## Features
- Sales Trend Analysis by Month
- Profit Analysis by Category
- Sub-Category Profit Comparison
- State-wise Sales Analysis
- Profit vs Sales Relationship
- Interactive Quarter and State Filters

## Tools Used
- Power BI
- Power Query
- DAX
